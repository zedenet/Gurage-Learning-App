# Guragina Language Learning App

A child-friendly Android app for learning the Gurage language through lessons and
interactive activities.

**Google Play:** 10K+ downloads · 4.7/5 rating

## Features

- Learn letters and numbers with audio.
- Explore root letters with pictures, sound, and examples.
- Practice writing letters with the drawing tool.
- Check language understanding with question-and-answer activities.
- Learn vocabulary for food, animals, family, body parts, and colors.
- Practice the days of the week and months through games.
